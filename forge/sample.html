// SAMPLE LAYOUT — COMPETITIVE ANALYSIS REVISIONS This file proposes 4 structural changes to forge.html based on analysis of theringlord.com, alchemygothic.com, chainmaillebyrd.com, and darkknightarmoury.com. No JavaScript required to read the layout changes.
1 Hero visual expanded (5fr/7fr split, SVG pattern). Competitors lead with full-width imagery. The 50/50 split underweights the product. A 42/58 split gives the visual slot dominance while the SVG chainmail pattern conveys craft intent instead of communicating "unfinished."
2 Commission flow moved directly below hero. Current page buries "how to order" as step 3 (after the SKU grid). For custom work, showing the purchase path early is the primary conversion lever. References like chainmaillebyrd.com make process visible before product details.
3 SKU cards now include portrait image slots (3:4 ratio). Every reference site shows product before price. Portrait (3:4) suits jewelry shots — shows full piece with context. Image slot at top shifts focus from "spec list" to "desirable object."
4 Gallery section redesigned: editorial 3-slot instead of 6 placeholders. Six "PHOTO PENDING" boxes communicate incompleteness loudly. A focused 3-slot layout with a main featured piece + 2 thumbs + Instagram CTA tells the same story (photography in progress) while still directing to where work can be seen.
